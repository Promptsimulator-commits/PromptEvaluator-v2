- (direction) Livrables attendus: spine (build substrate) + un support de presentation pour la demo au responsable
- (direction) Mode de travail: Coaching path
- (constraint) Aucun repo Git ni compte GitHub existant pour ce projet - a creer en tout debut de developpement (echo de la contrainte technique notee dans le PRD)
- (decision) Paradigme retenu: Option 2 - Next.js (framework tout-en-un, frontend + API routes), deploiement Vercel. Choix de l'utilisateur, contre ma recommandation initiale (Option 1 plus minimale) - assume malgre la courbe d'apprentissage pour un debutant.
- (version) Next.js 16.3 (Active LTS) verifie via recherche web (aout 2026), App Router production-ready, deploiement natif Vercel (npx vercel). Node.js 20.9+ requis. Source: releasebot.io/vercel changelog.
- (direction) Paradigme: Next.js App Router + API routes pour les appels serveur (execution LLM, notation, analyse), deploiement Vercel, cle API Anthropic en variable d'environnement Vercel jamais exposee client.
- (decision) Style: Tailwind CSS (rapide a iterer en vibecoding, tres bien supporte par les outils IA de generation de code). [ASSUMPTION] tag - a confirmer, l'utilisateur n'a pas explicitement tranche entre CSS pur et Tailwind.
- (decision) Decoupage API routes confirme: 3 routes distinctes (execution prompt x5, notation d'un resultat selon criteres, analyse 4 dimensions).
- (decision) SDK Anthropic officiel (@anthropic-ai/sdk) utilise exclusivement cote serveur (routes API), jamais cote client - confirme.
- (decision) Contrat API confirme: POST /api/execute {prompt}->{output}; POST /api/score {output,criteria[]}->{results:[{criterion,passed,explanation}]}; POST /api/analyze {prompt,runResults?}->{dimensions:[{name,status,explanation,example}]}. Erreurs uniformes: {error} + HTTP 500 sur toutes les routes.
- (decision) Environnement: un seul environnement Vercel (pas de staging), ANTHROPIC_API_KEY en variable d'environnement Vercel.
- (decision) Etat client: React state local (useState), pas de lib de state management globale - pas de persistance requise (non-goal PRD).
- (version) Tailwind CSS 4.3.3 (verifie via recherche web, publie juillet 2026). @anthropic-ai/sdk 0.123.0 (verifie via recherche web npm, publie recemment).
- (decision) AD-4 ajoute suite a auto-revue adversariale: orchestration des 5 executions cote client (pas de route serveur agregatrice), et regle explicite sur l'echec partiel (abandon complet de l'evaluation, jamais de moyenne sur un sous-ensemble).
